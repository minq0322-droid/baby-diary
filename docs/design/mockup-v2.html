이 일기장의 약속

아이 한 명, 하루 한 장. 배경은 고른 크레용 한 색으로 가득 채워요. 페이지마다 색을 바꾸거나, 설정에서 가족 전체·아이별 기본 색을 정해요.

글씨는 Gaegu 400 / 700, 메모 22px · 보조 글씨도 15px 이상. 아빠와 엄마의 글은 따로 감싸, 나중에 각자의 손글씨를 자연스럽게 입혀요. 선은 2.2px, 둥근 펜촉과 고정된 씨앗으로 조금씩 흔들리게 그려요.

밝은 종이에는 먹색 #1E2326, 숲·밤에는 우윳빛 #F5F0E1. 다크 화면은 부드러운 밤 #2B2F3A / 표면 #353A47, 페이지는 깊은 크레용 색으로 바뀌어요. 개나리·코랄·민트의 다크 색은 글씨 대비 4.5:1 이상을 위해 한 톤 더 깊게 조정했어요. 모든 작은 페이지에도 잉크 윤곽을 남겨요.

날짜는 옆으로 220ms, 1.5° 기울며 넘어가요. 움직임 줄이기를 켜면 바로 바뀌어요. 터치 영역 44px 이상, 위아래 안전 영역을 존중해요. 색 고르기·아이 전환·날짜·검색·달력·그리기를 직접 눌러 보세요.

이 파일은 저장하지 않는 디자인 시안이에요. 사진은 CSS로 만든 예시, 글씨체 업로드는 자리 표시예요. 실제 동기화와 백업 연결은 앱 구현에서 이어가요.
