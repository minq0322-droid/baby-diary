이 시안의 생각

이름 없이 얼굴과 날짜만 남긴 작은 하늘이에요. 밤에는 짙은 청록·남색에서 보랏빛으로 이어지는 하늘에 별 120개가 빛나요. ‘별’ 스위치로 반짝임과 느린 사선 흐름을 고를 수 있고, 5–9초마다 별똥별 1–3개가 오른쪽 위에서 왼쪽 아래로 지나가요.

낮에는 차분한 초록·청록 정원에 나무, 덤불, 작은 꽃이 겹쳐져요. 반딧불 25마리가 은은하게 깜빡이며 떠돌고, 화면 밖으로 나가면 다시 나타나요. 별 움직임 선택은 밤에 적용돼요.

얼굴은 왼쪽 위의 빛과 오른쪽 아래의 그림자를 담은 구체예요. 햇살은 정확히 30개로, 12시가 오늘이고 시계 방향으로 하루씩 과거예요. 기록한 날만 따뜻하게 빛나며 살짝 흔들려요. 조비안은 28일(3·11일 전 비움), 또이는 12일 기록한 예시예요. 30일 모두 기록하면 태양 전체가 밝아지고 후광이 천천히 맥동해요.

얼굴에 마우스를 올리거나 길게 누르면 2초 동안 ‘최근 30일 중 28일 기록’ 같은 말풍선이 보여요. 키보드 초점과 접근성 이름에도 같은 정보를 제공해요. 얼굴을 짧게 누르면 그 위치에서 오늘 페이지로 둥글게 커져요.

사진첩 → 원형 이동·확대 → 확정 흐름과 지난 사진 재사용·삭제를 유지해요. 512px 원형 사진은 두 프레임에 함께 반영돼요. 사진과 기록은 이 탭의 메모리에만 보관하며 새로고침하면 초기화돼요.

배경 캔버스 하나와 SVG 햇살을 하나의 시간 기반 루프로 그려요. 프레임마다 레이아웃을 읽지 않으며 모션 줄이기에서는 별·반딧불·햇살·얼굴을 정지하고 별똥별을 생략해요. 숨겨진 탭에서는 루프를 멈춰요. 실제 모바일 기기에서 성능과 터치감을 확인해 주세요.
