## 1. 격자 (휴대폰 4열 · 좌우 16 · 세로 8 · 390 기준)

- 위 막대 52: 왼쪽 원형 `‹` 44(16에서 시작) · 가운데 제목 17 굵게 · 오른쪽 원형 아이콘 44(오른쪽 16에서 끝).
- 피드: 날짜 머리 40(위에 붙음) → 글쓴이 줄 44(아바타 28 · 이름 · `⋯`) → **종이 면 화면 폭 가득(좌우 0)**, 그림 4:3 · 손글씨 22/1.35 좌우 20 → 동작 줄 44(하트 · 댓글 · 배지) → 다음 장까지 20.
- 아래 탭: 떠 있는 캡슐 좌우 20 · 높이 60 · 홈 표시줄 위 8 · 아이콘만 26.
- 쓰기 화면: 위 막대 52 · 엄마/아빠 전환 줄 48 · 장 번호 줄 32 · 그림 · 글 · 아래 줄 72(댓글 · 저장 · 색).

## 2. 기능별 세부 배치

- **피드 한 장**: 끝선 — 글쓴이 줄 왼쪽 16 = 날짜 머리 왼쪽 16 = 동작 줄 첫 아이콘 중심 16+22. 종이 면만 0~390.
- **아이 고르기 칩 줄**(전체 · 첫째 · 둘째): 날짜 머리 위, 왼쪽 16, 높이 32, 가로 스크롤 없음(셋뿐).
- **쓰기 화면 저장 상태**: 장 번호 줄 오른쪽 끝(16) — `임시 저장됨` / `저장됨` / `임시 저장 실패`.

## 4. 레퍼런스 (기능마다)

- **피드 한 장 = 인스타그램 게시물**: 글쓴이 줄 → 화면 폭 가득 사진 → 동작 줄(하트·댓글) → 글 → 댓글 한 줄. 두 번 톡 = 하트. 출처: Instagram iOS 앱(작가 지정 "인스타그램처럼").
- **시간순 기록 + 1년 전 오늘 + 형제 나란히**: Pieceful(App Store 설명, https://apps.apple.com/kr/app/pieceful-effortless-baby-log/id6756474655).
- **떠 있는 캡슐 탭 · 원형 뒤로**: HOUSE §10 (App Store · 아이폰 메모 캡처).
- **나가기 세 가지**: iOS 메일 초안 닫기(「초안 저장 / 초안 삭제 / 취소」), Day One 편집 화면은 늘 자동 보관.
- **앱 아이콘 고르기**: iOS 대체 아이콘(Day One·Things·Bear 의 설정 › 앱 아이콘 격자). 웹 앱은 `apple-touch-icon` 을 홈 화면에 추가하는 순간 읽으므로, 설정에서 고른 뒤 추가하도록 안내.
- **파일 고르기 단추**: 아이폰 「파일」 시트를 여는 둥근 단추(입력 칸은 숨김).
