테마는 그대로(지금 것, 낮·밤). 화면 세 장: 기록 피드(인스타그램처럼), 쓰기 화면(그림이 날아가지 않게), 설정의 앱 아이콘 고르기. 이름과 글은 모두 지어낸 예시입니다.

1 · 기록 피드

기록

  • 한 장 = 화면 폭 가득 종이색 면 → 손글씨 전체 → 하트·댓글 줄(인스타그램 순서). 면을 두 번 톡 하면 하트.
  • 맨 위 「1년 전 오늘」(있는 날만), 날짜 머리는 위에 붙어 따라옴. 끝까지 내리면 다음 달이 저절로.
  • 아래 탭: 바닥에 붙은 흰 띠 → 떠 있는 캡슐, 아이콘만, 지금 화면이 켜짐(전엔 목록에서 「홈」이 켜져 있었음). 「목록」은 「기록」으로.
  • 왼쪽 위 ‹ 홈(돌아갈 곳 이름), 오늘 쓰기는 오른쪽 아래 +.

그림과 글은 이 기기에 임시로 남아 있어요.

  • 획 하나·글 한 줄마다 기기에 임시 저장, 앱을 내리거나 꺼져도 다시 열면 되살아남. 장 번호 줄 오른쪽에 임시 저장됨.
  • 도구 막대의 「완료」 → 그리기 끝(저장과 헷갈리지 않게). 그리는 동안에도 아래 글이 보임.
  • 저장 안 한 채 나가면 저장하고 나가기 / 임시로 두고 나가기 / 버리고 나가기.
  • 글 칸을 눌러도 검은 테두리 없음(커서만), 왼쪽 위 ‹ 기록, 원형 단추는 종이 위 반투명.
