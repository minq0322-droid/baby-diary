# 첫 화면 시안 조사 메모 (2026-10-26)

## 사용자 요청
첫 화면(홈)을 "잔잔하면서도 아름다운" 화면으로. 시안 3개:
- **A. 큐빅 아트 (모뉴먼트 밸리)**: 배경에 별똥별, 가운데 돌릴 수 있는 3차원 구조물, 그 위에서 아이 프로필을 고름.
- **B. 파스텔 프로필 대시보드**: 파스텔 톤 카드에 아이 사진 + 현재 상황(태어난 일수/출산 D-day, 최근 일기 작성량)을 간단한 그래픽으로.
- **C. 떠다니는 얼굴**: 무지 화면 또는 배경(텔레토비 햇님처럼 하늘·언덕) 위에 아이 프로필 사진이 해·행성처럼 둥둥. 얼굴을 누르면 입력 화면. 이름 표시 없음.
공통: 아이 프로필 사진 등록(사진첩 → 원형 크롭, 카톡처럼), 예전 프로필 사진도 지우기 전까지 보관.

## 조사에서 얻은 것
- Monument Valley(ustwo): 모든 화면이 "벽에 걸 수 있는 그림"이 목표. 일본 판화·미니멀 조각·Escher 영향, 선명하지만 채도 낮은 톤과 단순한 조명으로 입체감. 레벨 구조물 자체가 UI 역할을 함(메뉴를 따로 두지 않음). — Wikipedia, MacStories, Unity case study
- 웹 디오라마: 직교(orthographic) 카메라로 아이소메트릭 느낌, 드래그 회전, 별 배경 + 별똥별 레이어 조합이 흔함. — freefrontend javascript-diorama, Framer interactive galaxy
- 파스텔 육아 앱: 프로필(사진·이름·생일) → 나이/주차 기반 진행 표시가 일반적. 부드러운 파스텔 디자인 시스템 + 명확한 위계. — Contra baby tracker, Space-O case study
- 떠다니는 아바타/궤도 UI: 중심 요소 주위로 아바타가 돌거나 떠다님, 아이콘은 회전해도 똑바로 유지. 백그라운드 탭에서 타이머가 느려지므로 시간 기반(경과 시간으로 위치 계산) 애니메이션이 필요. — 21st.dev orbiting avatars, Framer XOrbit, solar system template

## 제약 (최종 앱 = claude.ai Artifact + PWA)
- 외부 스크립트는 cdnjs 등 허용 CDN만. 무거운 3D 라이브러리보다 CSS 3D/SVG 아이소메트릭이 폰에서 가볍고 안전. three.js는 꼭 필요할 때만.
- 폰 성능: 60fps 목표, requestAnimationFrame + 경과 시간 기반, 화면이 안 보이면 멈춤. prefers-reduced-motion이면 정지 상태로.
- 다크/라이트 모두. 터치 44px 이상. 한 화면에서 "누를 것"이 한눈에.
- 실제 아이 사진 대신 시안에서는 일러스트 얼굴 플레이스홀더 사용. 텔레토비 이미지는 분위기 참고만(복제 금지).

## Claude 제안
- A: 하늘색→남보라 그라데이션 밤하늘 + 별똥별(가끔, 잔잔하게). 가운데 아이소메트릭 "작은 집/탑" 디오라마(CSS 3D 큐브 조합). 좌우로 돌리면 90°씩 스냅, 각 면(또는 각 층 창문)에 아이 얼굴 원형이 붙어 있어 정면에 온 아이를 탭하면 그 아이 페이지. 하단에 오늘 날짜만 작게.
- B: 연민트 배경, 아이마다 큰 카드 1장(좌우 스와이프). 원형 사진 + "생후 1,170일" 또는 "만나기까지 D-34" 큰 숫자, 최근 30일 기록을 점 30개 잔디(작성한 날 색칠), 이번 주 엄마/아빠 페이지 수. 카드의 큰 버튼 "오늘 쓰기".
- C: 기본은 무지 파스텔 하늘, 옵션으로 언덕·구름 배경. 두 아이 얼굴이 햇살 테두리(SVG 광선)를 두르고 천천히 떠다님(서로 부딪히지 않게 부드러운 궤적). 오늘 아직 안 쓴 아이는 살짝 반짝임. 탭하면 얼굴이 커지며 페이지로 전환.
